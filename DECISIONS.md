# Decisions

Cross-platform only. Per-platform: `mac/DECISIONS.md`, `android/DECISIONS.md`, `mac-native/DECISIONS.md`. Newest at top.

- **2026-07-06 — Mac substrate = minimal native daemon, not the vendored Handy app (Peter).** Supersedes the vendored-Handy decision below (same day). Handy's robustness was two specific low-level choices, not its Rust/Tauri stack: (1) a self-healing CGEventTap (`handy-keys` re-enables it every 100 ms + re-derives fn from OS flags), (2) non-deadlocking audio teardown (cpal `Stream::drop` never re-enters the CoreAudio HAL lock, unlike PortAudio's `Pa_CloseStream`). Everything else in the 36 MB Tauri app — webview, overlay, settings UI — was cost with no benefit for an invisible daemon (it even added a recording overlay the user didn't want). So extract just those two choices into a ~1.9 MB headless daemon (`mac-native/`) that matches the Python daemon's behavior exactly. Vendored `desktop/` superseded (retire once the daemon has soaked). Details: `mac-native/DECISIONS.md`.
- **2026-07-06 — Mac substrate = vendored Handy, not the hand-rolled Python daemon (Peter).** *(Superseded same day — see above. Kept for the diagnosis, which still holds.)* The Python daemon's fragility was 100% its audio/event-tap layer (PortAudio teardown deadlock → process-suicide loop; CGEventTap dropping fn-up). Rather than keep patching it, vendor [Handy](https://github.com/cjpais/Handy) (MIT, native Rust/Tauri) into `desktop/` via `git subtree --squash` and keep our shared MLX whisper service as the ASR brain via a new `RemoteSocket` engine. **Vendor, not fork** — one repo, adopt upstream by release tag only, custom logic in new files + 1-line seams (`desktop/PATCHES.md`). Auto-updater disabled (it would overwrite our tree). The two root failures are structurally gone (cpal `Stream::Drop`, tap re-enable+reconcile) or healed in-process. Python daemon retained until soak + R1–R18 parity gate clears.
