# Decisions — MUTTER mac

- **2026-06-11** — Phantom-fn + spew fix: trigger only on flagsChanged with keycode 63 (real fn key). Why: arrow/nav/F-keys also toggle the fn *flag*, phantom-recording ambient audio that whisper hallucinated into typed text ("Thank you." ×500). Backstop: main loop polls `CGEventSourceFlagsState` every 0.5 s — fn physically up on 2 consecutive polls while LISTENING → finish (heals tap-disabled missed releases; debounced so a transient misread can't cut a live dictation). Empirical: synthetic posted flag events do NOT register in `CGEventSourceFlagsState` (verified 2026-06-11), so only physical state drives the heal. Acoustic gate replaces `finish()`'s forced `has_spoken`: transcribe only with VAD-confirmed speech or ≥3 RMS-cleared 50 ms blocks — silence never reaches whisper. Phrase blacklist → `collapse_repeats` (PTT = deliberate press; "okay"/"thank you" must type; repeat-loops bound to 1 instance, any phrase — the old regex missed multi-word loops).
- **2026-06-11** — Never-drop: `capture()`/`transcribe()` split + FIFO tx queue. State guards capture only and returns IDLE at fn-up; one consumer thread transcribes/injects in order, so a slow transcribe can't swallow the next press; >120 s holds loop capture in segments. Whisper failure → clip persisted `~/.mutter/pending/*.wav` + notification; inject failure → pbcopy + notification. Quick-tap race (finish before capture init wedged the daemon ≤120 s) closed via finish-requested flag + `begin_turn()`.
- **2026-06-09** — Capture from built-in mic always (`stt._builtin_input_device`), never the system-default input. Why: a Bluetooth default input forces A2DP→HFP on open — fails `-10851` while audio plays, else silent rms=0; built-in has neither mode and leaves BT music in A2DP. Tradeoff: ignores BT mics entirely. To allow BT mic later, gate on a user setting before the default fallthrough.
- **2026-05-29** — Two-layer fix for silent-wedge mode (daemon "running" but fn no-ops forever). `stt.py:_close_stream`: `abort` not `stop` — `Pa_StopStream` drains the input buffer and deadlocks on `FinishStoppingStream` after CoreAudio HAL disruption (sleep/wake, device change); abort is non-blocking, frames are already callback-copied. Side benefit: clean SIGTERM no longer hangs. `daemon.py`: 180 s turn deadline (120 s capture cap + 60 s grace for transcribe + slow Screen-Sharing injection) armed on fn-down, cleared in worker's `finally`; overrun → `os._exit(1)` → launchd `KeepAlive` respawns. Why brutal exit: clean shutdown calls `listener.stop()` → same wedged mutex. Cheap because warm whisper lives in the separate service. 14 tests pass; fn → text re-verified.
- **2026-05-17** — Trimmed `mutter/stt.py` and `mutter/whisper_client.py` to drop API surface mutter never uses (Listener.cancel/current_rms/is_recording/`__enter__`/`__exit__`/test seams, WhisperClient.transcribe_file). Why: ~60% of mutter's `.py` lines were vendored verbatim from CLAWS (stt.py) and whisper-service (whisper_client.py), bringing capabilities mutter doesn't call. ~100 LoC removed; all 14 tests pass; fn → text verified. Commit `3d1950b`.
